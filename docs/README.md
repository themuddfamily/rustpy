# RustPy help

This guide follows the IDE's workflows and Settings tree. It describes what the
IDE does; the [roadmap](../roadmap.md) records how complete each feature is and
[HANDOFF.md](../HANDOFF.md) lists which platforms and integrations have been
verified.

| Task | Guide |
|---|---|
| Open a project, choose Python, understand trust | [Getting started](help/getting-started.md) |
| Edit, navigate, inspect, refactor and configure the editor | [Editor and code insight](help/editor.md) |
| Run, debug, test and inspect live processes | [Run and tools](help/run-and-tools.md) |
| Commit, review history and collaborate | [Version control and collaboration](help/vcs-and-collaboration.md) |
| Customize windows, shortcuts, settings and plugins | [Workspace settings](help/workspace.md) |
| Keyboard reference and remapping | [Keymap reference](keymap.md) |
| Headless commands, launcher and CI tests | [Command-line launcher](command-line.md) |
| Configuration, caches and per-project files | [Configuration directories](configuration-directories.md) |
| Scientific cells and tables | [Scientific mode](scientific-mode.md) |
| Share interpreter-library indexes | [Shared indexes](shared-indexes.md) |
| Use RustPy analysis in another editor | [LSP](lsp.md) |
| Understand crate boundaries and lifecycle authority | [Architecture](architecture.md) |
| Contribute code and tests | [Contributing](contributing.md) |
| Known issues | [Known issues](review-backlog.md) |
| Run the quality gates | [Quality gates](quality.md) |
| Prepare a release | [Release checklist](release.md) |

Settings › Editor mirrors General, Code Editing, Appearance, Font, Color Scheme,
Code Style, Inspections, Completion, Smart Keys, Console, Tabs, Gutter Icons,
Postfix Completion, File Types, Encodings, Injections, Reader Mode and related
pages. Settings search and Find Action are preferable to memorizing menu paths;
a contributed keymap or plugin can change the displayed shortcut or action list.
