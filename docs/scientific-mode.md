# Scientific mode

Choose **View → Scientific Mode** to arrange SciView beside the existing Documentation viewer and Python Console. The Documentation pane follows the symbol at the editor caret; its existing pin and history controls remain available. Console variables can be shown or hidden in **Settings → Tools → Python Scientific**. Automatic mode selects the scientific workspace for Python files containing scientific imports or `#%%` cells when the scientific layout preference is enabled.

In console or debugger variables, choose **View as Array/DataFrame**, then **Open in SciView** where offered. SciView retains separate data tabs for their originating console or debugger. Refresh requests return to that owner. Debugger pages become snapshots when execution resumes or the suspension changes; they remain readable and exportable. Refresh needs the original idle console or suspended debugger. Notebook data pages use the same viewer; kernel execution remains owned by the notebook.

The shared adapter accepts pandas DataFrames and Series, NumPy arrays, PyTorch/TensorFlow/JAX tensors, Polars tables and Series, and Python collections. Higher-dimensional tensors require an explicit slice such as `0, :, 0:100`. Pages have bounded rows, columns and rendered text; accelerator values transfer only requested cells. Use row and column offsets to move through larger values.

Column headers sort the loaded page numerically where possible. Filters accept expressions such as `amount > 1 && name != 'hidden'`; backticks quote column names with spaces. These filters and transpose affect the loaded rectangle. Column statistics describe the loaded source page, with count, numeric count, missing values, minimum, maximum, mean and population standard deviation. They do not claim whole-dataset statistics. Number formats accept `.6g`, `.3f`, `.2e` and corresponding `{:...}` forms, with optional per-column overrides. Heatmaps offer Viridis, Blue–Red and grayscale maps. Resize columns manually or use Fit columns.

Copy TSV, CSV export and Excel `.xlsx` export use the currently loaded, filtered/transposed rectangle. Excel stores displayed cell representations as strings to preserve text and prevent formulas from executing. Enter an export path explicitly. Open in new tab creates a retained snapshot; Floating opens the same data view in a separate IDE window. Auto-refresh polls the original owner at the configured interval and waits while it is busy.

The Plots tab collects console, debugger and notebook output. Select a thumbnail, zoom or fit the image, save its bytes to a chosen path, copy its data URL, or clear the gallery. Matplotlib uses the injected Agg capture backend. Plotly and Bokeh `show()` calls are captured as self-contained HTML when those libraries are imported in a captured session. Interactive HTML and SVG open only through the explicit **Open interactive web view** action in the system browser, where native pan, zoom and other plot controls run. Notebook trust decisions occur before publication to SciView. Gallery entries and capture logs have size limits. Capture settings update idle consoles immediately and debugger capture at the next suspension; new debug sessions receive the backend before user imports.

Python cell markers accept both `#%%` and `# %%`. Their gutter menu provides Run Cell, Run and Select Below, Run Above and Debug Cell. Debug Cell attaches to the selected Python console, preserves its existing variables, and compiles the cell under its original file and line numbers. Resume the console debugger before submitting another cell. Cell separators, capture, layout, refresh defaults, page size, formats, color maps and gallery size are configured on the Python Scientific settings page.
