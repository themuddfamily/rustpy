RustPy — native database dependency additions
============================================

Prepared from the 56 external Cargo.lock package additions in a6e93349 and
subsequent integrated lock correction e67f35f3. This conservative supplement
includes optional and build-only locked dependencies; inclusion does not assert
that every listed package is linked in every platform binary. It supplements,
and does not replace, the existing bundled resource notices or the release
Cargo dependency license/advisory gate. redis-rs is a Rust client library; these
notices do not bundle or license externally provisioned Redis/MongoDB servers.

For packages offering MIT OR Apache-2.0 (or additional alternatives), the MIT
alternative is retained below. redis-rs uses BSD-3-Clause, tiny-keccak CC0-1.0,
and xxhash-rust BSL-1.0. Exact cached source filenames and SHA256s identify the
verbatim license texts retained here. No package source was modified.

The mongodb, mongodb-internal-macros, mongocrypt, and mongocrypt-sys crates
declare Apache-2.0 in their published Cargo.toml but the cached crate payloads
contain no LICENSE or NOTICE files. The already-retained standard Apache-2.0
agreement is included below for those declarations; no package-specific NOTICE
or copyright statement is invented. mongocrypt is optional (in-use-encryption
is not enabled by RustPy's explicit MongoDB feature set).
